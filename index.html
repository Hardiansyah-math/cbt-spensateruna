Login Peserta

Masukkan NIS dan tanggal lahir sesuai data sekolah, lalu token ujian. Nama dan kelasmu diambil langsung dari database ujian, seperti pada CBT resmi.

TOKEN UJIAN
ASAS2026
Salin token di atas ke kolom Token Ujian.

Mode darurat: database ujian tidak dapat dihubungi. Isi nama dan kelas secara manual di bawah ini, lalu tekan Login lagi. Hasilmu tetap terkirim ke rekap, tapi tidak terverifikasi database.

Tata Tertib Peserta
  1. Kerjakan soal secara mandiri dan jujur.
  2. Dilarang membuka catatan, buku, atau aplikasi lain selama ujian.
  3. Waktu ujian 120 menit. Jawaban terkumpul otomatis saat waktu habis.
  4. Periksa kembali jawaban sebelum menekan tombol Kumpulkan Jawaban.

Login Admin (Guru)

Catatan: jawaban dan nilaimu otomatis terkumpul ke rekap guru setelah kamu menekan Kumpulkan Jawaban. Kalau pengiriman gagal karena internet, nilai tetap tersimpan di perangkat ini.
